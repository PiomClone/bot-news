# Инструкция по настройке mTLS (авторизация по сертификату)

Эта инструкция поможет вам настроить безопасный доступ к админ-панели бота.

## Шаг 1: Генерация сертификатов
В корне проекта выполните команду:
```bash
make certs
```
Скрипт создаст папку `certs/` и сгенерирует все нужные файлы. 
**Важно:** В конце скрипт попросит ввести пароль для экспорта сертификата клиента. Запомните его, он понадобится в Шаге 3.

## Шаг 2: Настройка бота
В вашем файле `.env` установите следующие параметры:
```env
TLS_ENABLED=true
SERVER_CERT=certs/server.crt
SERVER_KEY=certs/server.key
CA_CERT=certs/ca.crt
```
Перезапустите бота. Теперь админка доступна **только** по `https://` и **только** при наличии сертификата.

## Шаг 3: Установка сертификата в браузер

Скачайте файл `certs/client.p12` на свое устройство.

### Google Chrome / Microsoft Edge / Brave (Windows/macOS)
1. Откройте **Настройки** -> **Конфиденциальность и безопасность** -> **Безопасность**.
2. Найдите пункт **Настроить сертификаты** (или **Управление сертификатами устройств**).
3. В открывшемся окне перейдите на вкладку **Личные** и нажмите **Импорт**.
4. Выберите файл `client.p12`.
5. Введите пароль, который вы указывали в Шаге 1.
6. Перезапустите браузер.

### Firefox
1. Откройте **Настройки**.
2. В поиске введите `сертификаты`.
3. Нажмите кнопку **Просмотр сертификатов**.
4. Перейдите на вкладку **Ваши сертификаты** и нажмите **Импортировать**.
5. Выберите файл `client.p12` и введите пароль.

### iOS (iPhone)
1. Отправьте файл `client.p12` себе (например, через AirDrop или почту).
2. Откройте файл. Система скажет "Профиль загружен".
3. Перейдите в **Настройки** -> **Основные** -> **VPN и управление устройством**.
4. Нажмите на загруженный профиль и выберите **Установить**.

## Шаг 4: Проверка
Перейдите по адресу вашего сервера через `https://` (например, `https://localhost:8080`).
Браузер покажет окно с выбором сертификата. Выберите `bot-news-client` и нажмите ОК.

*Примечание: Так как сертификат самоподписанный, браузер может выдать предупреждение "Подключение не защищено". Нажмите "Дополнительно" -> "Перейти на сайт (небезопасно)". Это нормально для частного использования.*
